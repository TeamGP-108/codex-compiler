# 🇧🇩 বাংলা জাজ - অনলাইন কোড কম্পাইলার

একটি সম্পূর্ণ বাংলা ভাষায় তৈরি অনলাইন জাজ সিস্টেম যা Wasmer Edge-এ হোস্ট করার জন্য ডিজাইন করা হয়েছে।

## 🌟 ফিচারসমূহ

- **১২+ প্রোগ্রামিং ল্যাঙ্গুয়েজ সাপোর্ট**: পাইথন, জাভাস্ক্রিপ্ট, জাভা, সি++, সি, রুবি, পিএইচপি সহ আরও অনেক
- **দ্রুত এক্সিকিউশন**: ৫ সেকেন্ডের মধ্যে ফলাফল
- **নিরাপদ স্যান্ডবক্স**: অবিশ্বস্ত কোড নিরাপদে চালানোর জন্য
- **REST API**: সহজ JSON API ইন্টিগ্রেশন
- **ওয়েব ইন্টারফেস**: ব্রাউজার থেকে সরাসরি ব্যবহারের জন্য UI
- **অ্যাসিঙ্ক্রোনাস সাপোর্ট**: ব্যাকগ্রাউন্ডে কোড প্রসেসিং
